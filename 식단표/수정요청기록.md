# 일주일 식단표: 써 보고 고친 기록 (4단계)

처음 만든 뒤, 직접 써 보면서 아래처럼 요청하고 고쳤어요. 위에서부터 시간 순서예요.

| 순서 | 요청 | 고친 내용 |
|---|---|---|
| 1 | 못 먹는 재료와 옵션을 더 넣어 주세요 | 못 먹는 재료 6개 → 10개, 옵션 2개 → 5개 |
| 2 | 다른 테마로도 만들어 주세요 | 다크, 크림, 레트로 테마 추가 |
| 3 | 크림색이 크림색이 아니에요 (친구 의견) | 크림을 진짜 아이보리 색으로 바꾸고, 예전 갈색은 "모카"로 이름 변경. 민트, 하늘, 라벤더, 복숭아 추가 (총 9개) |
| 4 | 다이어트, 단백질 위주 식단 옵션 | "가벼운 식단", "단백질 위주" 추가 |
| 5 | 저염, 탄수화물 적게 | 두 옵션과 밥 없는 메뉴 추가 |
| 6 | 고혈압, 콜레스테롤 환자도 쓸 수 있게 | 치료용이 아니라 **참고용**이라는 경고와 함께 "고혈압 참고", "콜레스테롤 참고" 추가 |
| 7 | 배달과 직접 해먹기를 선택하게 | "일주일에 배달·외식 몇 번"과 배달 메뉴 추천 추가 |
| 8 | 저염인데 배달로 죽을 추천했어요 | **분류 실수였어요.** 저염·고혈압을 켜면 배달은 샐러드류만 나오게 고치고, 저염 메뉴는 직접 고른 목록으로 바꿨어요. 메뉴와 옵션도 크게 늘렸어요 |
| 9 | 설정이 너무 길어요 | 8줄짜리 버튼으로 줄이고, 누르면 선택 창이 열렸다 닫히게 변경 |
| 10 | 선택 창 안에 항목을 더 넣어 주세요 | 못 먹는 재료 22개, 식단 목적 11개, 식성 11개, 조리 10개로 확대 |
| 11 | 맞는 메뉴가 없는 빈칸을 없애 주세요 | 메뉴 96개로 늘리고 아침, 저녁 메뉴 보강. 옵션 하나씩과 자주 쓰는 조합 38개는 빈칸 없음 확인 |
| 12 | 맨 위를 간략하고 멋지게 | 제목과 설명을 줄이고, 이모지와 그라데이션 제목으로 꾸밈. 배지는 뺐어요 |
| 13 | "맞는 메뉴가 없어요"가 뜨지 않게, 메뉴를 더 많이 | 메뉴를 127개로 늘리고, 딱 맞는 메뉴가 없으면 **가장 가까운 메뉴**를 추천하며 못 맞춘 조건을 ⚠️로 표시. 못 먹는 재료, 채식, 비건, 매운 음식 빼기는 절대 어기지 않음. 옵션 2개 조합 495개 전부 빈칸 없음 확인 |
| 14 | (점검 중 발견) 선택 창이 겹쳐 열림 | 창이 열려 있는 동안 뒤쪽 화면을 막고, 겹쳐 열려도 정리되게 수정 |

## 아직 부족한 점
- 서로 모순되는 옵션(예: 저염 + 해산물 위주)을 겹치면 가장 가까운 메뉴가 나오고, 못 맞춘 조건이 ⚠️로 표시돼요.
- 영양 수치(칼로리, 나트륨 등)는 계산하지 않았어요. 모든 분류는 재료를 보고 나눈 **참고용**이에요.
- 재료 이름으로 빼는 옵션(버섯, 양파 등)은 배달 메뉴에는 적용되지 않아요.
- 📋 복사하기 버튼은 직접 눌러 확인하지 못했어요.
